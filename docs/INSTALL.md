# 처음 설치하기 (갤럭시 Z 폴드8)

개발 경험이 없어도 따라 할 수 있게 쓴 안내입니다. 30분쯤 걸립니다. 흑백 런처는 Play 스토어에 없으므로 PC와 USB 케이블로 설치하고, 이때 흑백 권한도 함께 줍니다.

준비물:

- Windows PC 또는 Mac
- 데이터 전송이 되는 USB-C 케이블 (충전 전용 케이블은 안 됩니다)

## 1. 개발자 옵션 켜기

1. 폰에서 **설정 > 휴대전화 정보 > 소프트웨어 정보**로 갑니다.
2. **빌드번호**를 7번 연달아 누릅니다.
3. 잠금 화면 PIN을 입력하면 '개발자 모드를 켰습니다'라는 안내가 나옵니다.

## 2. USB 디버깅 켜기

1. **설정 > 개발자 옵션**으로 갑니다(설정 목록 맨 아래에 새로 생깁니다).
2. **USB 디버깅**을 켭니다.

## 3. 자동 차단기 잠시 끄기

삼성 자동 차단기가 켜져 있으면 PC에서 보내는 USB 명령과 앱 설치가 막힙니다.

1. **설정 > 보안 및 개인정보 보호 > 자동 차단기**로 갑니다.
2. 끕니다. '잠시 후 자동으로 다시 켜기' 같은 선택지가 있으면 설치하는 동안에는 해제해 두세요.

설치가 끝나면 10단계에서 다시 켭니다.

## 4. PC에 adb 설치

adb는 PC에서 폰에 명령을 보내는 구글의 공식 도구입니다(Android SDK Platform-Tools).

### Windows

1. <https://developer.android.com/tools/releases/platform-tools> 에서 **SDK Platform-Tools for Windows**를 내려받습니다.
2. 압축을 풀어 `C:\platform-tools` 폴더가 되게 합니다. 이 폴더 안에 `adb.exe`가 있어야 합니다.
   설치 스크립트가 이 위치를 자동으로 찾으므로 PATH 설정은 하지 않아도 됩니다.
   (winget을 쓴다면 `winget install Google.PlatformTools`로 설치해도 됩니다.)
3. 나중에 폰을 연결했는데도 '연결된 기기가 없습니다'가 계속 나오면 [삼성 USB 드라이버](https://developer.samsung.com/android-usb-driver)를 설치하세요.

### macOS

[Homebrew](https://brew.sh)가 있으면 터미널에서:

```sh
brew install --cask android-platform-tools
```

Homebrew가 없으면 위 주소에서 **SDK Platform-Tools for Mac**을 받아 압축을 풀고, 나온 `platform-tools` 폴더를 5단계에서 APK를 받을 폴더(예: 다운로드)에 그대로 두세요. 설치 스크립트가 옆에 있는 `platform-tools` 폴더를 자동으로 찾습니다.

## 5. 앱과 설치 스크립트 받기

GitHub 저장소의 **Releases**에서 가장 최근 버전을 열고, 다음 파일을 **같은 폴더**(예: 다운로드)에 받습니다.

- `monolauncher-<버전>.apk` — 앱
- Windows: `install.ps1` / Mac: `install.sh` — 설치 스크립트

## 6. 폰 연결

1. USB 케이블로 폰과 PC를 연결하고 폰 잠금을 풉니다.
2. 폰에 **'USB 디버깅을 허용하시겠습니까?'** 창이 뜨면 '이 컴퓨터에서 항상 허용'을 체크하고 **허용**을 누릅니다.
   창이 바로 안 뜨면 7단계에서 스크립트를 실행할 때 뜹니다. 그때 허용하고 스크립트를 다시 실행하세요.

## 7. 설치 스크립트 실행

### Windows

1. 파일 탐색기에서 5단계의 폴더를 엽니다.
2. 빈 곳을 오른쪽 클릭해 **터미널에서 열기**를 누릅니다(Windows 10은 Shift를 누른 채 오른쪽 클릭 > **PowerShell 창 열기**).
3. 다음을 붙여 넣고 Enter를 누릅니다.

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

### macOS

1. **터미널** 앱을 엽니다(Spotlight에서 '터미널' 검색).
2. 다음을 입력합니다. 다른 폴더에 받았다면 `~/Downloads` 대신 그 폴더를 적습니다.

   ```sh
   cd ~/Downloads
   bash install.sh
   ```

### 결과 읽기

모든 단계에 `[완료]`가 나오면 성공입니다. 문제가 생기면 스크립트가 이유를 알려 줍니다.

| 메시지 | 할 일 |
|---|---|
| adb를 찾을 수 없습니다 | 4단계를 다시 확인하세요. |
| 연결된 기기가 없습니다 | 케이블, 2단계(USB 디버깅), 3단계(자동 차단기)를 확인하세요. |
| 'USB 디버깅을 허용하시겠습니까?' 창을 허용한 뒤… | 폰의 허용 창을 누르고 다시 실행하세요. |
| 설치가 막혔습니다 | 자동 차단기가 다시 켜졌는지 확인하고 끈 뒤 다시 실행하세요. |
| 흑백 권한이 부여되지 않았습니다 | 자동 차단기를 끈 상태로 다시 실행하세요. |

## 8. 기본 홈 앱으로 지정

스크립트가 '기본 홈 앱으로 지정됨'이라고 했다면 건너뜁니다. 아니라면:

1. 폰의 홈 버튼을 누릅니다. 홈 앱을 고르는 창이 뜨면 **흑백 런처**를 고르고 **항상**을 누릅니다.
2. 창이 뜨지 않으면 **설정 > 애플리케이션 > 기본 앱 선택 > 홈 화면 앱**에서 흑백 런처를 고릅니다(메뉴 이름은 One UI 버전에 따라 조금 다를 수 있습니다).

폰을 접어 **커버 화면**에서도 흑백 런처가 뜨는지 확인하세요.

## 9. 앱에서 확인

1. 화면 전체가 흑백인지 봅니다.
2. **종료**를 누르고 5초를 기다리면 색이 돌아옵니다.
3. 종료 상태에서 **설정**을 엽니다.
   - 등록 앱: 교보eBook for 삼성, 밀리의서재, YouTube Music, 카카오맵, Google Home이 있는지 확인하고, 빠졌으면 추가합니다.
   - 루틴 변수: 집에서 '현재 위치를 집으로 저장'을 누르면 `home_lat`(위도), `home_lng`(경도)가 채워집니다. 직접 넣을 때는 구글 지도에서 집을 길게 누르면 `37.5665, 126.9780`처럼 좌표가 나옵니다. 앞이 위도, 뒤가 경도입니다.
4. **시작**을 눌러 다시 흑백으로 돌아갑니다.
5. **집 가기** 버튼을 눌러 카카오맵 길찾기가 열리는지 확인합니다.

## 10. 마무리: 자동 차단기 켜기, USB 디버깅 끄기

1. **설정 > 보안 및 개인정보 보호 > 자동 차단기**를 다시 켭니다.
2. **설정 > 개발자 옵션 > USB 디버깅**을 끕니다.

USB 디버깅을 켜 두면 PC로 언제든 흑백을 풀 수 있어 상시 우회로가 됩니다. 업데이트할 때만 켜세요. 개발자 옵션 맨 위의 스위치를 꺼서 개발자 옵션 전체를 끄면 USB 디버깅도 함께 꺼집니다.

## 업데이트할 때

같은 순서를 반복하면 됩니다. 앱을 지우지 말고 그대로 덮어 설치하세요. 설정과 흑백 권한이 유지됩니다.

1. USB 디버깅 켜기 (2단계)
2. 자동 차단기 끄기 (3단계)
3. Releases에서 새 APK 받기 (5단계)
4. 폰 연결 후 설치 스크립트 실행 (6~7단계)
5. 자동 차단기 켜기, USB 디버깅 끄기 (10단계)

주의:

- 업데이트는 **같은 서명 키**로 만든 APK로만 됩니다. Releases의 APK끼리는 항상 같은 키입니다. 직접 빌드한 디버그 APK와 섞으면 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`로 실패합니다.
- 서명 키를 잃어버려 어쩔 수 없이 앱을 지워야 한다면, **먼저 런처에서 '종료'를 눌러 색을 되돌린 뒤** 지우세요. 흑백 설정은 앱을 지워도 남습니다. 다시 설치할 때 설치 스크립트가 흑백 권한을 다시 주지만, 등록 앱·루틴 같은 설정은 처음부터 다시 해야 합니다.
